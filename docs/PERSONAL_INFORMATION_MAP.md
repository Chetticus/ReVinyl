## Workbook-to-archive mapping

`scripts/import_workbook.py` extracts rows after the field-header row into `src/data/archive-workbook.json` and `src/data/website-content.json`. It validates slugs, joins, statuses, and one translation per language. It never changes the source workbook.

| Workbook sheet             | Frontend field / purpose                                                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `01_Artist`                | `lookups.artists`, `recording.artist`                                                                                                                    |
| `02_Album`                 | `lookups.albums`, `recording.album`; source `name` also maps to display `title`                                                                          |
| `03_Era`                   | `lookups.eras`, bilingual era text/year bounds, timeline                                                                                                 |
| `04_Genre`                 | `lookups.genres`, recording genre and filters                                                                                                            |
| `05_Region`                | `lookups.regions`, recording region and filters                                                                                                          |
| `06_Instrument`            | `lookups.instruments`, instrument filter                                                                                                                 |
| `07_Recording`             | All 30 slugs, years, DRAFT statuses, taxonomy links and source cover URLs                                                                                |
| `08_Recording_Translation` | 60 complete translation rows, including historical/cultural context, lyrics interpretation, listening notes, preservation value and lyrics-rights status |
| `09_Recording_Audio`       | Audio assets; empty in supplied workbook                                                                                                                 |
| `10_Recording_Instrument`  | Instrument links, bilingual roles and original confidence values                                                                                         |
| `11_Recording_Reference`   | Reference titles, URLs, publishers, years, notes and original verification statuses                                                                      |

`src/modules/archive/workbook.ts` implements accent-insensitive search, combined category filters, pagination, localized details, related records and chronological timelines. No missing update dates, full lyrics, audio or people are invented. `NEXT_PUBLIC_ARCHIVE_SOURCE=workbook` is the default; `api` switches public reads back to the backend. Backend admin taxonomy reads always use backend IDs. The live backend import is now complete; API mode reads the published catalog managed through admin. The 35 newly imported drafts remain private until published. This import did not deploy the frontend changes.

Legacy unused finance-learning components under `src/components/home/Session*` and `component-home/*` are inherited template content, not workbook-derived claims. They are not mounted by the current home pages. No workbook-backed replacement exists for their course outcomes or statistics; do not enable them as ReVinyl claims without real supporting content.
